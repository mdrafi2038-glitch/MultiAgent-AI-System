GitHub Plugin

Checking connection…

Build Android APKs by triggering an existing GitHub Actions workflow, checking its progress, and downloading its artifacts.

Connect once: In Render → this service → Environment, add GITHUB_TOKEN with repository Contents: Read and Actions: Read & Write permissions. Keep the token private; it is never entered into chat or shown in this dashboard.

Open Render Environment settings

Run a GitHub Actions build

The target repository must already contain a workflow with workflow_dispatch enabled. For an APK, that workflow must build the Android project and upload the APK as an artifact.

Universal API Plugin Hub

Connect websites/services that provide an HTTPS API. Define allowed API actions; credentials stay in Render Environment as environment variables. GET actions are read-only. Every change-making action needs a separate confirmation.

Safety: GitHub Actions runs only when you explicitly press Start GitHub build. The GitHub plugin does not run arbitrary shell commands or expose your token.
